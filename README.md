# Symbion 蓝色版

给 Cursor 用的蓝色首页规则。公开页：https://lulu2467.github.io/symbion-web/

把这个仓库克隆下来，整个文件夹放进 Cursor 的个人 skills 目录，文件夹名保持 `symbion-blue`，里面要直接有 `SKILL.md`。

个人 skills 目录一般是 `C:\Users\<你>\.cursor\skills\symbion-blue`。如果 Cursor 用的是 Agent Store，放到该 store 的 `skills\symbion-blue`。

装好后新开一个对话。改蓝色首页、Cosmo、Community、Kanban、设置或账户菜单时会用上。绿色主题不用这份。
