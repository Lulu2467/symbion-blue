# 颜色

蓝色只覆盖 `html[data-theme="blue"]`。下面的 `--green` 在蓝色里是钢青，不是绿色。

| 用途 | 值 |
| --- | --- |
| 正文 | `#000000` |
| 次要字 | `#656d76` |
| 标签 | `#71777d` |
| 分割线 | `#e6e8ec` |
| 页面 | `#ffffff` |
| 强调 | `#3c7a94` |
| 强调按下 | `#316479` |
| 浅底 | `#ebf5fa` |
| 悬停浅底 | `#f4f8fa` |
| 中性悬停 | `#f6f7f8` |
| 胶囊描边 | `#c5d4de` |
| 胶囊悬停描边 | `#9eb8c6` |

大面积不要铺 `#3c7a94`。强调留在字、描边、当前页文字上。

`:root` 里的 `--green: #008b68` 保持不动。那是绿色主题。
