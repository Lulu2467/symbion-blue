# 按钮

蓝色的「进入」和 Summon：

- 高 32px，圆角 999px
- 白底，描边 `#c5d4de`，字 `#3c7a94`，13px，字重 600
- `padding: 1px 16px 0`
- `display: inline-flex; align-items: center; justify-content: center; text-align: center; line-height: 1`
- 悬停底 `#ebf5fa`，描边 `#9eb8c6`

不要做成大块实心青。已召唤：底 `#f4f7f8`，字 `#6e7378`，边 `#e3e6e8`。

Summon 的显示不要写进蓝色尺寸规则。见 [gotchas.md](../../gotchas.md)。

正例：[examples/good-cases/capsule-button.css](../../examples/good-cases/capsule-button.css)
