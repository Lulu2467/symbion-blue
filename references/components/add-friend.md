# 添加好友

从 Community 加号菜单进入。只在蓝色显示这三项菜单。

| 项 | 值 |
| --- | --- |
| 菜单文案 | Add a friend |
| 标题 | Add a friend |
| 空状态 | Type a name or an email to add someone. |
| 搜索占位 | Search name or email |
| 没有结果 | No matching people |
| 新人按钮 | Add |
| 已在列表 | Message |
| 底部按钮 | 无。`.sheet-actions` 隐藏 |
| 关闭 | 右上角 × |

点 Add 会在左侧打开这个人的对话，并出现一句 Added。这是本页里的结果。不要再加一层「添加成功」，也不要假装有服务器。

不出现：自己、Citta、孪生。没输入时不要铺出全部名单。
